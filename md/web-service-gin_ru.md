# Руководство: Разработка RESTful API с Go и Gin

В этом руководстве представлены основы создания RESTful веб-сервиса API с использованием Go и веб-фреймворка Gin (Gin Web Framework).

Вы получите максимум пользы от этого руководства, если имеете базовое знакомство с Go и его инструментарием. Если это ваше первое знакомство с Go, ознакомьтесь с руководством [Tutorial: Get started with Go](/doc/tutorial/getting-started) для быстрого введения.

Gin упрощает многие задачи кодирования, связанные с созданием веб-приложений, включая веб-сервисы. В этом руководстве вы будете использовать Gin для маршрутизации запросов, получения деталей запроса и маршалинга JSON для ответов.

В этом руководстве вы создадите RESTful API сервер с двумя конечными точками (endpoints). Ваш пример проекта будет репозиторием данных о винтажных джазовых записях.

Руководство включает следующие разделы:

1. Проектирование конечных точек API.
2. Создание папки для вашего кода.
3. Создание данных.
4. Написание обработчика для возврата всех элементов.
5. Написание обработчика для добавления нового элемента.
6. Написание обработчика для возврата конкретного элемента.

**Примечание:** Другие руководства см. в разделе [Tutorials](/doc/tutorial/index.html).

Чтобы попробовать это как интерактивное руководство, которое вы выполняете в Google Cloud Shell, нажмите кнопку ниже.

## Предварительные требования

- **Установка Go 1.16 или более поздней версии.** Инструкции по установке см. в разделе [Installing Go](/doc/install).
- **Инструмент для редактирования кода.** Подойдет любой текстовый редактор.
- **Командный терминал.** Go хорошо работает в любом терминале на Linux и Mac, а также в PowerShell или cmd в Windows.
- **Инструмент curl.** На Linux и Mac он уже должен быть установлен. На Windows он включен в сборку Windows 10 Insider 17063 и более поздних версий. Для более ранних версий Windows может потребоваться его установка. Подробнее см. в статье [Tar and Curl Come to Windows](https://docs.microsoft.com/en-us/virtualization/community/team-blog/2017/20171219-tar-and-curl-come-to-windows).

## Проектирование конечных точек API

Вы создадите API, который предоставляет доступ к магазину, продающему винтажные записи на виниле. Поэтому вам нужно предоставить конечные точки, через которые клиент может получать и добавлять альбомы для пользователей.

При разработке API вы обычно начинаете с проектирования конечных точек. Пользователи вашего API добьются большего успеха, если конечные точки будут понятными.

Вот конечные точки, которые вы создадите в этом руководстве.

**/albums**

- `GET` — Получить список всех альбомов, возвращенный в формате JSON.
- `POST` — Добавить новый альбом из данных запроса, отправленных в формате JSON.

**/albums/:id**

- `GET` — Получить альбом по его ID, возвращая данные альбома в формате JSON.

Далее вы создадите папку для вашего кода.

## Создание папки для вашего кода

Для начала создайте проект для кода, который вы будете писать.

1. Откройте командную строку и перейдите в домашний каталог.

   На Linux или Mac:

   ```
   $ cd
   ```

   На Windows:

   ```
   C:\> cd %HOMEPATH%
   ```

2. С помощью командной строки создайте каталог для вашего кода под названием web-service-gin.

   ```
   $ mkdir web-service-gin
   $ cd web-service-gin
   ```

3. Создайте модуль, в котором вы можете управлять зависимостями.

   Запустите команду `go mod init`, указав путь к модулю, в котором будет находиться ваш код.

   ```
   $ go mod init example/web-service-gin
   go: creating new go.mod: module example/web-service-gin
   ```

   Эта команда создает файл go.mod, в котором будут перечислены добавляемые вами зависимости. Подробнее о именовании модуля с путем к модулю см. в разделе [Managing dependencies](/doc/modules/managing-dependencies#naming_module).

Далее вы спроектируете структуры данных для обработки данных.

## Создание данных

Для простоты в этом руководстве данные будут храниться в памяти. Более типичный API взаимодействовал бы с базой данных.

Обратите внимание, что хранение данных в памяти означает, что набор альбомов будет теряться каждый раз, когда вы останавливаете сервер, а затем воссоздаваться при его запуске.

#### Написание кода

1. Используя текстовый редактор, создайте файл called main.go в каталоге web-service. В этом файле вы будете писать код на Go.

2. В начало файла main.go вставьте следующее объявление пакета.

   ```
   package main
   ```

   Автономная программа (в отличие от библиотеки) всегда находится в пакете `main`.

3. Под объявлением пакета вставьте следующее объявление структуры `album`. Вы будете использовать его для хранения данных альбома в памяти.

   Теги структуры, такие как `json:"artist"`, определяют, каким должно быть имя поля при сериализации содержимого структуры в JSON. Без них JSON использовал бы имена полей структуры с заглавной буквы — стиль, менее распространенный в JSON.

   ```
   // album представляет данные о музыкальном альбоме.
   type album struct {
       ID     string  `json:"id"`
       Title  string  `json:"title"`
       Artist string  `json:"artist"`
       Price  float64 `json:"price"`
   }
   ```

4. Под добавленным объявлением структуры вставьте следующий срез структур `album`, содержащий данные, которые вы будете использовать для начальной загрузки.

   ```
   // albums - срез для начальных данных альбомов.
   var albums = []album{
       {ID: "1", Title: "Blue Train", Artist: "John Coltrane", Price: 56.99},
       {ID: "2", Title: "Jeru", Artist: "Gerry Mulligan", Price: 17.99},
       {ID: "3", Title: "Sarah Vaughan and Clifford Brown", Artist: "Sarah Vaughan", Price: 39.99},
   }
   ```

Далее вы напишете код для реализации вашей первой конечной точки.

## Написание обработчика для возврата всех элементов

Когда клиент делает запрос `GET /albums`, вы хотите вернуть все альбомы в формате JSON.

Для этого вы напишете следующее:

- Логику для подготовки ответа
- Код для сопоставления пути запроса с вашей логикой

Обратите внимание, что это обратный порядок того, как они будут выполняться во время выполнения, но вы сначала добавляете зависимости, а затем код, который от них зависит.

#### Написание кода

1. Под кодом структуры, добавленным в предыдущем разделе, вставьте следующий код для получения списка альбомов.

   Эта функция `getAlbums` создает JSON из среза структур `album`, записывая JSON в ответ.

   ```
   // getAlbums возвращает список всех альбомов в формате JSON.
   func getAlbums(c *gin.Context) {
       c.IndentedJSON(http.StatusOK, albums)
   }
   ```

   В этом коде вы:

   - Пишете функцию `getAlbums`, которая принимает параметр [`gin.Context`](https://pkg.go.dev/github.com/gin-gonic/gin#Context). Обратите внимание, что вы могли дать этой функции любое имя — ни Gin, ни Go не требуют определенного формата имени функции.

     `gin.Context` — самая важная часть Gin. Он содержит детали запроса, проверяет и сериализует JSON и многое другое. (Несмотря на похожее название, это отличается от встроенного пакета [`context`](/pkg/context/) в Go.)

   - Вызываете [`Context.IndentedJSON`](https://pkg.go.dev/github.com/gin-gonic/gin#Context.IndentedJSON) для сериализации структуры в JSON и добавления его в ответ.

     Первым аргументом функции является код состояния HTTP, который вы хотите отправить клиенту. Здесь вы передаете константу [`StatusOK`](https://pkg.go.dev/net/http#StatusOK) из пакета `net/http`, чтобы указать `200 OK`.

     Обратите внимание, что вы можете заменить `Context.IndentedJSON` на вызов [`Context.JSON`](https://pkg.go.dev/github.com/gin-gonic/gin#Context.JSON) для отправки более компактного JSON. На практике отступная форма намного удобнее при отладке, а разница в размере обычно невелика.

2. В начале файла main.go, прямо под объявлением среза `albums`, вставьте код ниже для привязки функции обработчика к пути конечной точки.

   Это настраивает ассоциацию, в которой `getAlbums` обрабатывает запросы к пути конечной точки `/albums`.

   ```
   func main() {
       router := gin.Default()
       router.GET("/albums", getAlbums)

       router.Run("localhost:8080")
   }
   ```

   В этом коде вы:

   - Инициализируете маршрутизатор Gin с помощью [`Default`](https://pkg.go.dev/github.com/gin-gonic/gin#Default).

   - Используете функцию [`GET`](https://pkg.go.dev/github.com/gin-gonic/gin#RouterGroup.GET) для связывания HTTP-метода GET и пути `/albums` с функцией обработчика.

     Обратите внимание, что вы передаете *имя* функции `getAlbums`. Это отличается от передачи *результата* функции, что вы сделали бы, передав `getAlbums()` (обратите внимание на скобки).

   - Используете функцию [`Run`](https://pkg.go.dev/github.com/gin-gonic/gin#Engine.Run) для присоединения маршрутизатора к `http.Server` и запуска сервера.

3. В начале файла main.go, прямо под объявлением пакета, импортируйте пакеты, необходимые для поддержки только что написанного кода.

   Первые строки кода должны выглядеть так:

   ```
   package main

   import (
       "net/http"

       "github.com/gin-gonic/gin"
   )
   ```

4. Сохраните main.go.

#### Запуск кода

1. Начните отслеживать модуль Gin как зависимость.

   В командной строке используйте [`go get`](/cmd/go/#hdr-Add_dependencies_to_current_module_and_install_them) для добавления модуля github.com/gin-gonic/gin в качестве зависимости для вашего модуля. Используйте точечный аргумент, чтобы означать «получить зависимости для кода в текущем каталоге».

   ```
   $ go get .
   go get: added github.com/gin-gonic/gin v1.7.2
   ```

   Go разрешил и загрузил эту зависимость для удовлетворения объявления импорта, добавленного на предыдущем шаге.

2. Из командной строки в каталоге, содержащем main.go, запустите код. Используйте точечный аргумент, чтобы означать «запустить код в текущем каталоге».

   ```
   $ go run .
   ```

   После запуска кода у вас есть работающий HTTP-сервер, которому вы можете отправлять запросы.

3. Из нового окна командной строки используйте `curl` для выполнения запроса к вашему запущенному веб-сервису.

   ```
   $ curl http://localhost:8080/albums
   ```

   Команда должна отобразить данные, которыми вы инициализировали сервис.

   ```
   [
       {
           "id": "1",
           "title": "Blue Train",
           "artist": "John Coltrane",
           "price": 56.99
       },
       {
           "id": "2",
           "title": "Jeru",
           "artist": "Gerry Mulligan",
           "price": 17.99
       },
       {
           "id": "3",
           "title": "Sarah Vaughan and Clifford Brown",
           "artist": "Sarah Vaughan",
           "price": 39.99
       }
   ]
   ```

Вы запустили API! В следующем разделе вы создадите другую конечную точку с кодом для обработки запроса POST для добавления элемента.

## Написание обработчика для добавления нового элемента

Когда клиент делает запрос POST по адресу `/albums`, вы хотите добавить альбом, описанный в теле запроса, к существующим данным альбомов.

Для этого вы напишете следующее:

- Логику для добавления нового альбома в существующий список.
- небольшой фрагмент кода для маршрутизации запроса POST к вашей логике.

#### Написание кода

1. Добавьте код для добавления данных альбома в список альбомов.

   Где-нибудь после операторов импорта вставьте следующий код. (Конец файла — хорошее место для этого кода, но Go не применяет порядок объявления функций.)

   ```
   // postAlbums добавляет альбом из JSON, полученного в теле запроса.
   func postAlbums(c *gin.Context) {
       var newAlbum album

       // Вызовите BindJSON для привязки полученного JSON к newAlbum.
       if err := c.BindJSON(&newAlbum); err != nil {
           return
       }

       // Добавьте новый альбом в срез.
       albums = append(albums, newAlbum)
       c.IndentedJSON(http.StatusCreated, newAlbum)
   }
   ```

   В этом коде вы:

   - Используете [`Context.BindJSON`](https://pkg.go.dev/github.com/gin-gonic/gin#Context.BindJSON) для привязки тела запроса к `newAlbum`.
   - Добавляете структуру `album`, инициализированную из JSON, в срез `albums`.
   - Добавляете код состояния 201 в ответ вместе с JSON, представляющим добавленный альбом.

2. Измените вашу функцию `main`, чтобы она включала функцию `router.POST`, как показано ниже.

   ```
   func main() {
       router := gin.Default()
       router.GET("/albums", getAlbums)
       router.POST("/albums", postAlbums)

       router.Run("localhost:8080")
   }
   ```

   В этом коде вы:

   - Связываете метод POST по пути `/albums` с функцией `postAlbums`.

     С Gin вы можете связать обработчик с комбинацией HTTP-метода и пути. Таким образом, вы можете отдельно маршрутизировать запросы, отправленные на один путь, в зависимости от метода, который использует клиент.

#### Запуск кода

1. Если сервер все еще запущен с предыдущего раздела, остановите его.

2. Из командной строки в каталоге, содержащем main.go, запустите код.

   ```

   ```

3. Из другого окна командной строки используйте `curl` для выполнения запроса к вашему запущенному веб-сервису.

   ```
   $ curl http://localhost:8080/albums \
       --include \
       --header "Content-Type: application/json" \
       --request "POST" \
       --data '{"id": "4","title": "The Modern Sound of Betty Carter","artist": "Betty Carter","price": 49.99}'
   ```

   Команда должна отобразить заголовки и JSON для добавленного альбома.

   ```
   Content-Length: 116
   ```

4. Как и в предыдущем разделе, используйте `curl` для получения полного списка альбомов, который вы можете использовать для подтверждения добавления нового альбома.

## Написание обработчика для возврата конкретного элемента

Когда клиент делает запрос к `GET /albums/[id]`, вы хотите вернуть альбом, ID которого соответствует параметру пути `id`.

Для этого вы:

- Добавите логику для получения запрошенного альбома.
- Сопоставите путь с логикой.

#### Написание кода

1. Под функцией `postAlbums`, добавленной в предыдущем разделе, вставьте следующий код для получения конкретного альбома.

   Эта функция `getAlbumByID` извлечет ID в пути запроса, затем найдет соответствующий альбом.

   ```
   // getAlbumByID находит альбом, значение ID которого соответствует параметру id,
   // отправленному клиентом, затем возвращает этот альбом в качестве ответа.
   func getAlbumByID(c *gin.Context) {
       id := c.Param("id")

       // Перебираем список альбомов,寻找
       // альбом, значение ID которого соответствует параметру.
       for _, a := range albums {
           if a.ID == id {
               c.IndentedJSON(http.StatusOK, a)
               return
           }
       }
       c.IndentedJSON(http.StatusNotFound, gin.H{"message": "album not found"})
   }
   ```

   В этом коде вы:

   - Используете [`Context.Param`](https://pkg.go.dev/github.com/gin-gonic/gin#Context.Param) для получения параметра пути `id` из URL. При сопоставлении этого обработчика с путем вы включите заполнитель для параметра в пути.

   - Перебираете структуры `album` в срезе,寻找 ту, значение поля `ID` которой соответствует значению параметра `id`. Если она найдена, вы сериализуете эту структуру `album` в JSON и возвращаете ее в качестве ответа с кодом HTTP `200 OK`.

     Как упоминалось выше, реальный сервис, скорее всего, использовал бы запрос к базе данных для выполнения этого поиска.

   - Возвращаете ошибку HTTP `404` с [`http.StatusNotFound`](https://pkg.go.dev/net/http#StatusNotFound), если альбом не найден.

2. Наконец, измените вашу функцию `main`, чтобы она включала новый вызов `router.GET`, где путь теперь `/albums/:id`, как показано в следующем примере.

   ```
   func main() {
       router := gin.Default()
       router.GET("/albums", getAlbums)
       router.GET("/albums/:id", getAlbumByID)
       router.POST("/albums", postAlbums)

       router.Run("localhost:8080")
   }
   ```

   В этом коде вы:

   - Связываете путь `/albums/:id` с функцией `getAlbumByID`. В Gin двоеточие перед элементом в пути означает, что этот элемент является параметром пути.

#### Запуск кода

1. Если сервер все еще запущен с предыдущего раздела, остановите его.

2. Из командной строки в каталоге, содержащем main.go, запустите код, чтобы запустить сервер.

   ```
   $ go run .
   ```

3. Из другого окна командной строки используйте `curl` для выполнения запроса к вашему запущенному веб-сервису.

   ```
   $ curl http://localhost:8080/albums/2
   ```

   Команда должна отобразить JSON для альбома с указанным вами ID. Если альбом не найден, вы получите JSON с сообщением об ошибке.

   ```
   {
       "id": "2",
       "title": "Jeru",
       "artist": "Gerry Mulligan",
       "price": 17.99
   }
   ```

## Завершенный код

Этот раздел содержит код приложения, которое вы создали с помощью этого руководства.

```go
package main

import (
    "net/http"

    "github.com/gin-gonic/gin"
)

// album представляет данные о музыкальном альбоме.
type album struct {
    ID     string  `json:"id"`
    Title  string  `json:"title"`
    Artist string  `json:"artist"`
    Price  float64 `json:"price"`
}

// albums - срез для начальных данных альбомов.
var albums = []album{
    {ID: "1", Title: "Blue Train", Artist: "John Coltrane", Price: 56.99},
    {ID: "2", Title: "Jeru", Artist: "Gerry Mulligan", Price: 17.99},
    {ID: "3", Title: "Sarah Vaughan and Clifford Brown", Artist: "Sarah Vaughan", Price: 39.99},
}

func main() {
    router := gin.Default()
    router.GET("/albums", getAlbums)
    router.GET("/albums/:id", getAlbumByID)
    router.POST("/albums", postAlbums)

    router.Run("localhost:8080")
}

// getAlbums возвращает список всех альбомов в формате JSON.
func getAlbums(c *gin.Context) {
    c.IndentedJSON(http.StatusOK, albums)
}

// postAlbums добавляет альбом из JSON, полученного в теле запроса.
func postAlbums(c *gin.Context) {
    var newAlbum album

    // Вызовите BindJSON для привязки полученного JSON к newAlbum.
    if err := c.BindJSON(&newAlbum); err != nil {
        return
    }

    // Добавьте новый альбом в срез.
    albums = append(albums, newAlbum)
    c.IndentedJSON(http.StatusCreated, newAlbum)
}

// getAlbumByID находит альбом, значение ID которого соответствует параметру id,
// отправленному клиентом, затем возвращает этот альбом в качестве ответа.
func getAlbumByID(c *gin.Context) {
    id := c.Param("id")

    // Перебираем список альбомов,寻找
    // альбом, значение ID которого соответствует параметру.
    for _, a := range albums {
        if a.ID == id {
            c.IndentedJSON(http.StatusOK, a)
            return
        }
    }
    c.IndentedJSON(http.StatusNotFound, gin.H{"message": "album not found"})
}
```
